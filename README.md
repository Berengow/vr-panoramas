# VR Панорамы

Просмотр 15 панорам 360° в VR-шлеме (Meta Quest, Pico), на ПК и на телефоне. Работает в браузере через WebXR (A-Frame), ничего устанавливать не нужно.

## Управление

| Где | Действие |
|---|---|
| Шлем | Курок / A / Y — следующая, B / X — предыдущая, боковая кнопка — меню выбора панорам |
| ПК | Стрелки ← →, колесо мыши — приближение, карусель внизу |
| Телефон | Свайп по карусели, гироскоп, щипок — приближение |

Ссылка на конкретную панораму: `…/#5`.

## Файлы

- `index.html` — приложение
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка как приложения
- `panoramas/hi/` — 6144×3072 (шлем, режим HD), `mid/` — 4096×2048 (ПК и телефон), `low/` — 1536×768 (быстрый показ), `thumbs/` — миниатюры; всё в WebP
- `vendor/aframe.min.js` — A-Frame 1.6.0
- `serve.ps1` — локальный сервер для проверки: http://localhost:8080

После замены панорам увеличьте версию кэша `vr-pano-vN` в `sw.js` и `index.html`.

Стоковые панорамы — [Poly Haven](https://polyhaven.com), лицензия CC0.
