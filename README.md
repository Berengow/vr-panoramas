# Медиа Хаб — виртуальный тур

5 панорам 360° студий Медиа Хаба для VR-шлема, компьютера и телефона. Работает в браузере через WebXR (A-Frame), ничего устанавливать не нужно.

Сайт: https://berengow.github.io/vr-panoramas/

## Управление

| Где | Действие |
|---|---|
| Шлем, контроллеры | Курок / A / Y — следующая, B / X — предыдущая, стик влево-вправо — листать, боковая кнопка или нажатие стика — меню (выбор лучом) |
| Шлем, руки | Щипок правой рукой — следующая, левой — предыдущая |
| ПК | Мышь — осмотреться, колесо — приближение, двойной клик — сброс; ← → / Пробел — листать, 1…9 — к панораме, F — полный экран, H — справка |
| Телефон | Палец или гироскоп — осмотреться, два пальца — приближение, карусель внизу |

Ссылка на конкретную панораму: `…/#3`.

Поддерживаются контроллеры Meta Quest, Pico, HTC Vive, Valve Index, Windows Mixed Reality и другие (через `laser-controls`), а также управление руками.

## Файлы

- `index.html` — приложение
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка как приложения
- `panoramas/hi/` — 8192×4096 (8K) (шлем, режим HD), `mid/` — 4096×2048 (ПК и телефон), `low/` — 1536×768 (быстрый показ), `thumbs/` — миниатюры; всё в WebP
- `og.jpg` — картинка для превью ссылки в мессенджерах и соцсетях
- `vendor/aframe.min.js` — A-Frame 1.6.0
- `serve.ps1` — локальный сервер для проверки: http://localhost:8080

После замены панорам увеличьте `VERSION` в `index.html` и версию кэша `vr-pano-vN` в `sw.js`.

Панорамы сняты на Ricoh Theta Z1, обработаны (шумоподавление с сохранением краёв, тёплая «ламповая» цветокоррекция, мягкое свечение ламп, чёткость и резкость, увеличение до 8K) и сжаты в WebP.
